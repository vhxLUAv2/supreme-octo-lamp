# Open-source client references

This project is adding independently implemented features informed by the public feature sets and documentation of these open-source Minecraft clients:

- [Meteor Client](https://github.com/MeteorDevelopment/meteor-client) — module-based client architecture and common utility-module concepts. Licensed GPL-3.0.
- [LiquidBounce](https://github.com/CCBlueX/LiquidBounce) — modular client architecture and utility features. Its repository source is licensed GPL-3.0, subject to the repository's stated exclusions.
- [Wurst7](https://github.com/Wurst-Imperium/Wurst7) — reference for common client-side utility modules.
- [Lambda Client](https://github.com/lambda-client/lambda) — reference for utility and automation feature ideas.

The new Fullbright, Zoom, and AutoTool classes in this integration are independent implementations; no source files have been copied from those upstream repositories. Their names describe common Minecraft client features. Before porting upstream source code directly, check the exact file's license, retain required notices, and comply with any copyleft obligations.
